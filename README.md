HarrisProject7 – Video Game Task List

What It Does

This Flask application is based on a video game development theme. It has a home page, an about page, and a task list page that displays five tasks.

What It's Built With

Python

Flask

HTML

CSS

Jinja2

How to Run It

Open the project folder in VS Code.

Open the terminal.

Activate the virtual environment.

Install Flask using pip install flask if needed.

Run the application using python app.py.

Open your browser and go to http://127.0.0.1:5000.

Screenshot Description

The application displays a simple video game development-themed website. The home page introduces the project, the about page explains the application, and the task list page displays five development-related tasks.
